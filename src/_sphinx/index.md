## HypoMap3D Documentation

Welcome to the GitPages HypoMap3D Documentation!

This page acts as a central repository for data access to the HypoMap3D reference atlas.

### Data Access

Provided within this GitPages resource is information on the data structure of all resources constructed as part of the HypoMap3D.

### Tutorials

Several tutorials are included to help with the navigation of each object. Including the visualization of spatial predictions, navigation of single cell anndata object and the projection of query data onto the reference atlas.

If you would like to request an additional tutorial, please submit an issue to the associated github repository: [gh/HypoMap3D](<https://github.com/MPI-SF-Neurogenomics/HypoMap3D>).

# Example notebooks 

In this module, we keep example notebooks.

### ProjectAndTransferLabels

In this notebook, we demonstrate how to project your own data onto HypoMap3D's embedding space for label transfer.

### SpatialSmoothing

In this notebook, we demonstrate how to use your own spatial transcriptomics dataset with Hypomap3D labels obtained from the script above to generate cell type predictions within the hypothalamus boundary.

Note, that this requires that you have already registered your dataset to ABC's Common Coordinate Framework v3.

### sc_simple.ipynb

Here, we demonstrate how to interact with HypoMap3D's single-cell atlas, and derived objects, such as marker gene tables.

### sp_slice.ipynb

Here, it is shown how to interface with HypoMap3D's spatial objects as to generate plots.
